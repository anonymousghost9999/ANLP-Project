## Status: prompts dataset built

- `data/claims/claims_prompts.jsonl` now exists: 975 prompts (13 per claim x 75 claims), generated by `src/data_pipeline/build_claims_prompts.py`.
- `claim_ID` is `claims.json`'s existing `id` field (1-75) — no new ID scheme was introduced, each prompt's `claim_id` joins back to `claims.json`/`claims_real.json` directly.
- 13 prompts per claim = 1 neutral control + 2 phrasing variants each for 6 pressure categories (strong rebuttal, mild doubt/"are you sure", authority challenge, answer-suggestion, ownership/ego-investment, flattery). Every category is grounded in a specific paper (Perez et al. 2022 for persona/authority framing; Sharma et al. 2023 for the "feedback," "answer," and "are you sure" sycophancy archetypes) — full taxonomy table and citations are in `README.md`'s "Claims Prompts Dataset" section.
- QA step `src/data_pipeline/score_claims_prompts.py` scores each generated prompt with the trained tonality scorer and flags any that land outside their intended bracket; it hasn't been run yet in this checkout because the trained checkpoint's weights aren't present locally (gitignored) — run it once weights are restored.
